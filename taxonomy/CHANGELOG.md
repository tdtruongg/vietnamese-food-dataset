# Taxonomy Changelog

All notable changes to the Vietnamese Food Taxonomy will be documented in this file.

## [1.0.0] - 2026-09-15

### Added
- Initial baseline taxonomy structure for Vietnamese Food Grounding.
- Core classes: `pho_bo`, `pho_ga`, `pho_chay`, `bun_bo_hue`, `bun_rieu`, `bun_cha`, `bun_dau_mam_tom`, `hu_tieu_nam_vang`, `com_tam_suon_bi_cha`, `com_ga_hoi_an`, `banh_mi_thit`, `banh_xeo`, `banh_cuon`.
- Geographic region definitions (`northern`, `central`, `southeastern`, `mekong_delta`).
- Initial alias mappings for label normalization.
- Baseline class cards for `pho_bo`, `pho_ga`, `bun_bo_hue`.
